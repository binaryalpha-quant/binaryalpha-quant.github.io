First launch

Expect a warning

These builds are not code-signed yet, so your operating system will warn you the first time you open the app. That means no certificate has been purchased — not that the download is unsafe.

01

Windows

SmartScreen shows “Windows protected your PC”. Click More info, then Run anyway.

02

macOS

Right-click the app in Applications and choose Open, then confirm. Double-clicking is blocked the first time only.

03

Linux

Mark the AppImage executable, or install the package:

chmod +x BinaryAlphaTrader-*.AppImage
./BinaryAlphaTrader-*.AppImage

sudo apt install ./BinaryAlphaTrader-*.deb
Antivirus

The trading engine is a bundled Python backend, and executables packed this way are a frequent source of antivirus false positives. If your AV quarantines the app, add an exclusion for the install directory and reinstall.

What you need

A Kalshi account

Sign up, then create API keys in your Kalshi settings. The app talks to Kalshi directly from your machine.

A license key

Ask in Discord. Keys are verified offline — the app never phones home.

Nothing else

No account, no cloud service. Keys and trade history live in a local database, encrypted at rest on Windows via DPAPI.

Safe by default

  • Demo + dry-run Both must be turned off before a real order goes out. The 15-minute crypto tab has its own separate live switch.
  • Daily limits Stop-loss, take-profit and trading-hours windows gate the engine.
  • Kill switch A master switch halts all trading immediately.
