Kalshi auto-trading

Whole-app trading shell

Local · offline license

Binary Alpha is a desktop terminal for Kalshi: configure the engine, watch flow, and keep keys on your machine. Safety rails ship on — demo environment and dry-run until you deliberately go live.

  • Whale tracker Surface large-flow activity so you can see where size is leaning before the engine acts.
  • Momentum scanner Scan short-horizon moves across the markets you care about — same shell as the trading engine.
  • Configurable engine Tune limits, hours, and switches from the desktop UI. Your API keys never leave the machine.

Research layer

Discover

Free market data

Scan memecoin momentum without leaving the terminal. Discover pulls public market data so you can research names, watch flow, and keep a local record — separate from Kalshi auto-trading.

  • DexScreener Pair and liquidity snapshots for tokens you are watching across supported DEXes.
  • GeckoTerminal Cross-chain pool context to compare venues and spot where activity is concentrating.
  • pump.fun Early-curve listings and momentum signals from the pump.fun feed.
  • Research recorder Capture notes and observations locally while you work a name — for research, not execution.

Setup

First launch

Expect a warning

These builds are not code-signed yet, so your operating system will warn you the first time you open the app. That means no certificate has been purchased — not that the download is unsafe.

01

Windows

SmartScreen shows “Windows protected your PC”. Click More info, then Run anyway.

02

macOS

Right-click the app in Applications and choose Open, then confirm. Double-clicking is blocked the first time only.

03

Linux

On Debian or Ubuntu the package handles its own dependencies:

sudo apt install ./BinaryAlphaTrader-*.deb

The AppImage runs anywhere but needs FUSE 2, which Ubuntu no longer installs by default (the package is libfuse2 before 24.04):

sudo apt install libfuse2t64
chmod +x BinaryAlphaTrader-*.AppImage
./BinaryAlphaTrader-*.AppImage

Or skip the dependency entirely — this unpacks and runs it with no system packages at all:

./BinaryAlphaTrader-*.AppImage --appimage-extract-and-run
Antivirus

The trading engine is a bundled Python backend, and executables packed this way are a frequent source of antivirus false positives. If your AV quarantines the app, add an exclusion for the install directory and reinstall.

Prerequisites

What you need

A Kalshi account

For auto-trading: sign up, then create API keys in your Kalshi settings. The app talks to Kalshi directly from your machine. Discover market data does not require Kalshi.

A license key

Ask in Discord. Keys are verified offline — the app never phones home.

Nothing else

No account, no cloud service. Keys and trade history live in a local database, encrypted at rest on Windows via DPAPI.

Defaults

Safe by default

  • Demo + dry-run Both must be turned off before a real Kalshi order goes out. The 15-minute crypto tab has its own separate live switch.
  • Daily limits Stop-loss, take-profit and trading-hours windows gate the engine.
  • Kill switch A master switch halts all trading immediately.
